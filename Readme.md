# 📚 C++ Algorithms & Problem Solving Level 4 - Course Solutions

This repository contains my personal solutions and implementations for all problems (**P01 to P64**) from **Course 8: Algorithms & Problem Solving Level 4**.

## 📂 Course Exercises Breakdown

* **P01 - P07:** Numbers conversion, Leap years, Time calculations, Day names, and Calendars.
* **P08 - P18:** Date ordering, comparisons, differences, and Age calculation.
* **P19 - P31:** Date arithmetic & increase operations (Days, Weeks, Months, Years, Decades, Centuries, Millenniums).
* **P32 - P45:** Date decrease operations and edge-case handling.
* **P46 - P52:** Advanced date utilities, business days, and end-of-period trackers.
* **P53 - P54:** Vacation and return-date calculators.
* **P55 - P60:** Period operations (Overlaps, lengths, and range checks).
* **P61 - P64:** Date validation, string parsing, and custom formatting.
